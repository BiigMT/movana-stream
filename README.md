# MOVANA — Movies & TV Streaming Platform

Current static website source for MOVANA.

- Public browsing landing page
- Original deployed design preserved
- Root entry point: `index.html` redirects to the original site at `/src/index.html`
- Main site source: `src/index.html` (single-file HTML with embedded styles and scripts)
- Vercel project connected to this GitHub repository for deployment

This repository currently contains the published frontend snapshot. Authentication, payments, and video streaming backend integrations are not yet fully connected.
